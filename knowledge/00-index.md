# 归岸 · 知识库索引

> 这份索引是给接手者（人或模型）看的第一份文件。它告诉你：这个项目是什么、知识放在哪、哪些结论可信、哪些还只是猜测。

## 一分钟版本

**归岸**是一个网页端产品，里面住着三个**相互独立**的 AI 朋友：

| 朋友 | 定位 | 核心约束 |
|---|---|---|
| 健康朋友 | 对身体、睡眠、饮食、运动研究很深的人 | 懂很多，但没资格给人下判断 |
| 成长朋友 | 走过弯路的人，覆盖学习与个人成长 | 只给一个很小的下一步，不给方法论清单 |
| 倾诉朋友 | 愿意听的人 | 不给建议，不做诠释，不承诺永远在 |

三个人格不是同一个 bot 的三种模式。各自的对话历史、记忆、说话方式互不串通——现实中你的三个朋友本来也不交换情报。

**这个产品最重要的一条设计不是「陪伴」，是「反替代」**：它必须在用户开始把它当唯一出口时主动后退。原因见 `01-product-positioning.md`，法律依据见 `04-safety-compliance.md`。

## 阅读纪律（重要）

知识库里每条陈述都带三种标记之一，**不要混用**：

- **【事实】** — 有可点开的出处，出处记在 `07-evidence-ledger.md`
- **【判断】** — 我们在事实基础上的推论或工程取舍，可能是错的
- **【待验证】** — 明确没有证据，写出来是为了不被误当成结论

如果一条内容没有标记，默认它没被核过，按【待验证】对待。

**特别提醒**：这个项目在早期有过几次「听起来很对但查了是错的」的结论（例如「WHO 把强迫症列入十大致残疾病」实为 1990 年数据、早已不在榜单）。`07-evidence-ledger.md` 里专门有一节记录这些被撤回的说法，读它是为了不重犯。

## 代码在哪

```
归岸/
├── 启动归岸.cmd        双击启动（只做转发，中文由 node 打印）
├── 设置模型密钥.cmd    双击填 API key
├── runtime/node.exe    打包的 Node 运行时（用户机器没有 Node）
└── app/
    ├── core/           运行时无关的对话内核（可直接 node 跑测试）
    │   ├── src/personas/     三份人格配置，产品最核心的资产
    │   ├── src/pipeline/     prompt 渲染、安全分诊、依赖检测、介入决策
    │   ├── src/memory/       记忆抽取与排序
    │   ├── src/compliance/   会话时长 + 年龄策略（法规硬要求）
    │   ├── src/content/      文案库（热线 7+31 省、危机协议、边界、6 个解压练习）
    │   ├── src/turn/         单轮编排
    │   └── test/             测试，跑法见下
    ├── server/         零依赖 HTTP 服务（七条路由，/api/relief 在鉴权之前）
    ├── evolve/         见岸·自适应演示台（自进化 + 三次认证）
    ├── scripts/        双击入口的实际逻辑
    └── web/            四个视图 + 常驻求助入口 + 热线面板 + 解压渲染器
```

跑测试（124 项，约 2 秒）：

```bash
cd app
npm test                    # 有系统 Node 时
../runtime/node.exe --test  # 只有打包运行时的时候
```

起服务：

```bash
cd app
LLM_MOCK=1 npm start     # 假模型，不花钱，只验流程
npm start                # 真模型（需密钥）
```

普通使用不需要命令行，双击 `启动归岸.cmd` 即可。

**改代码前必读** `../AGENTS.md`，里面列了六条不能动的约束，动了会破坏产品定位。

## 这个项目的来历

最初是为 BoHack 2026 天津青年黑客松「日新主题赛道」做的（原始方案见 `../research/日新赛道_作战方案.md`）。赛道后来没有继续，但产品判断留下来了，独立成一个新项目。

早期还做过一个聚焦强迫症的心理自助产品「见岸」。**早期只借架构范式**（core 与 IO 分离、人格独立配置、安全分诊前置），不复用品牌与内容；**2026-11-14 起改为有选择地迁入三块具体资产**：6 个解压练习的数据与渲染器、31 省热线数据、以及一组危机关键词（补进了归岸的分级词表）。迁入时改掉了 OCD 语境文案、统一成纸墨配色，省份数据标为【待验证】。详见 `05-engineering-stack.md` 第十一节与 `04` 第七节。两者的产品定位仍然不同：

- 见岸：面向强迫症人群，重点是「不给保证」这种专业干预姿态
- 归岸：面向普通人的日常陪伴，重点是「三个朋友 + 知道自己该退到哪里」
