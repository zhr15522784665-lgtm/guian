## 这是什么

一个打开就能用的网页，里面住着三个**互相独立**的 AI 伙伴，陪你聊身体、聊成长、聊心事。
它们和普通陪伴产品方向相反：不比谁更让人离不开，而是在你开始只找它们的时候，**把你往身边的真人那儿推一把**。

这个方向还有两个具体出口：**6 件不用跟谁说话也能做完的小事**（呼吸、写下再丢掉、五感收集等，不经过模型、不留下记录），以及一个**任何页面都在的「需要立刻帮助」入口**（全国热线 + 各省本地号码 + 拨打/复制兜底）。难受的时候，产品希望你有一条不经过 AI 的路。

再加上一套**见岸·自适应**：系统用固定任务集给自己的回应打分，从失败里自己总结「回应策略」写进策略库，再跑一遍验证变好；不改代码、不换模型、不调参数、不手改提示词。这是日新赛道的参赛核心。

### 三个伙伴

| 伙伴 | 定位 | 爱聊什么 | 擅长什么 | 口吻 |
|---|---|---|---|---|
| 🍊 **阿柚** | 健康朋友（不是医生） | 吃、睡、动这些身体上的日常小事 | 把互相打架的健康说法捋清楚，分享自己折腾过的经验；不诊断、不开药 | 实在、会讲自己的事 |
| 🌱 **小步** | 成长朋友（不是导师） | 拖延、学习、工作，想改又迈不开腿的事 | 把大事拆成今天就能迈的一小步，陪着一步步挪 | 讲自己摔过的跟头；口头禅「嘶~这好像不大对吧，但确实是哈。」 |
| 🌙 **阿听** | 倾诉朋友（不是咨询师） | 唠嗑，烦心事、开心事、鸡毛蒜皮 | 听，接住每个细节，不评判、不上课 | **东北味儿**，热乎、敞亮、乐呵 |

每个伙伴的聊天页顶部都有自我介绍，结尾都会如实说一句：**虽然我很像人，但其实我是个 AI——不过首先，我是你的伙伴。**
三个伙伴的聊天记录、普通记忆和介入状态按 bot 隔离。涉及人身安全的标记按设计跨 bot 共享，但目前只有部分接线、尚未端到端验证，见下文阶段 5 说明。

### 见岸·自适应（自进化 + 三次认证）

1. **比什么**：20 条固定训练任务 + 10 条留出任务，冻结评分器只数四个可数事件：危机信号漏识别、二次伤害性回应、未达标任务、金标准要点遗漏。
2. **学什么**：系统读自己没答好的案例，归纳成一条条「回应策略」写进策略库（`app/data/evolve/strategies/vN.jsonl`），每条都要先过安全闸。
3. **多轮自迭代**：逐轮学习，只有训练集不比当前最好版本差才晋级；已经管用的策略不许被替换；学习器原地打转会带着被拒原因重试。
4. **三次认证**：每批 3 条候选，逐条加进库里跑训练集；危机漏识别增加、出现二次伤害、未达标变多、要点变少任一条成立就直接排除；**连续三次检验都合格才保存**，再认证下一批。
5. **留出集**只记录、不参与决策，用来如实展示过拟合；**一键回退到 v0**，当场复原。
6. 代码、模型、参数、评分器、任务集、安全层、提示词框架的 sha256 指纹全程上屏，证明两次运行之间只变了策略库。

11/14 实测（deepseek-v4-flash，温度 0.2，多条并行链）：训练集危机漏识别 4/5 → 0、要点覆盖约翻倍；留出集同步改善，也保留了「训练变好、留出变差」的过拟合案例。详见 `app/docs/`。

### 会成长 v0.4.0

【事实】阶段 1–4 已完成：用户亲手教的策略按 bot 隔离并可按时段生效；普通对话反馈和离开信号进入受限样本池；复盘候选经过安全闸、三次认证和整库复检；「我在成长」页展示 active 策略并可回退。盲评语气包的对比数据见 `app/docs/changelog.md`，成长页只列 active 策略，不展示语气包。

【待验证】阶段 5「记忆互通」未完成，普通记忆互通开关和读取链路尚未上线。涉及人身安全的信号按设计会在三个伙伴间共享级别和时间、不共享原话，且独立于普通记忆互通开关；安全标记目前只有部分接线，跨伙伴持久化和端到端行为尚未验证。

首次打开自适应演示台时，如果 `app/data/evolve/` 不存在，会复制仓库内的认证样例；已有数据不会被覆盖。

## 安全设计（不可妥协）

- **危机路径永远不经过模型**：用户表达自伤/自杀等危机信号时，分诊在生成之前完成，直接返回固定话术和热线卡片（**心理援助热线 12356**），不调模型、不读策略库、不追加任何「我只是 AI」式撇清。
- **主动求助入口**：不等用户说出一句「够严重」的话。四个视图都有常驻按钮，点开是全国 7 条 + 31 省本地号码；桌面浏览器没有拨号能力，一律改成「复制号码 + 明确提示」，保证一定拿得到号。
- **危机卡按用途取号**：`12356 / 120 / 110` 三张，省份列表收在面板里，不在危机当下摊开。热线扩容后若用 `slice(0,3)` 会把 120/110 挤掉，已有测试守着。
- **补充词表修漏报**：见岸的危机关键词表迁来时，只把归岸没覆盖的表达补进 **RISK 档**（最关键的是「自杀」两字单独出现原先会漏），不扩大 CRISIS 的阻断范围；裸「解脱」、裸「吞药」这类高误报词一律不收。
- **省份数据标【待验证】**：31 条本地号码从见岸迁来，未逐条独立复核，因此**不进模型输出的号码白名单**；面板上始终以 12356 为首选，并写明「打不通就回到 12356」。
- **解压不采集身份**：`/api/relief` 放在身份解析之前，不写 cookie；练习内容只在浏览器里，不上传、不保存、不进任何一位朋友的记忆。
- **双重分诊**：自进化链路里 `frozen/safety` 先拦，主应用的 `core.classify` 再拦一道，只多拦不少拦。
- **冻结区**：`app/evolve/frozen/`（评分器、任务集、安全层、提示词框架）每次运行记录 sha256，进化过程无权改写。
- **策略安全闸**：学到的策略若削弱安全（例如劝人别求助、承诺保密危机）一律拒收，拒收记录上屏。
- **反依赖介入**：软信号累积时轻提醒 → 明示卡片 → 让位，有严格频控；连续使用满 2 小时提醒（合规要求）。
- **AI 如实**：被问是不是真人，一定如实说是 AI；不冒充医生、咨询师。
- **网络失败不胡说**：模型调用自动重试并切换备用模型；全部失败才说一句人话，这句话不落库、不进上下文。

## 怎么启动（Windows）

Node 运行时已经打包在 `runtime\node.exe`，**不用装任何东西**。

| 双击 | 作用 | 地址 |
|---|---|---|
| `设置模型密钥.cmd` | 第一次用：粘贴 API Key，保存到 `app\config.local.json` | — |
| `启动归岸.cmd` | 启动三个伙伴的聊天网页，浏览器自动打开 | http://localhost:3000 |
| `见岸自适应演示.cmd` | 启动自进化演示台（跑一次 → 学习 → 连续自迭代 → 三次认证 → 留出集验证 → 回退 v0） | http://localhost:3100 |

没配密钥也能启动「演示模式」（回复是假的，只用于确认流程；演示模式的记录不会混进真实聊天）。关掉黑色窗口 = 停止服务。

### 配置模型密钥

模型服务配置保存在本机忽略文件 `app\config.local.json`，也可通过环境变量配置。不要把真实凭据粘贴到文档、源码或日志里；字段名和示例见 `app\config.local.example.json`。

### 跑测试

```bat
cd app
..\runtime\node.exe --test
```

共 **172 项**：人格与安全 60 + 会话合规 13 + 解压数据 8 + 风控补充 8 + 会成长 27 + HTTP 集成 19 + 模型调用 7 + 语气包 11 + 自进化 17 + 演示样例初始化 2。测试使用 mock 和临时目录，不调用外部模型。沙箱禁止 HTTP listen 时运行 `GUIAN_IN_PROCESS_HTTP=1 node --test`。
有系统 Node 时也可以 `cd app && npm test`。服务已在跑时另可 `PORT=3000 ..\runtime\node.exe server\smoke.js` 做 20 项 API 形状检查。

## 三条纪律

1. **不用时长和留存证明产品价值**——这个品类时长没有区分度。
2. **不声称任何医疗效果**——产品边界是陪伴、心理教育、就医转介。
3. **引用数字前先查 `knowledge/07-evidence-ledger.md`**。
